# ounce-admin — لوحة أدمن منصة أوقية

لوحة **مالك البرنامج وحده**: المتاجر المشتركة، باقاتها، سقف فروعها، مدة
اشتراكها، التجديد والإيقاف، نموذج تشغيل كل فرع، وسجل كل العمليات.

مبنية على مفاهيم صفحة «تصاريح الاشتراك» المحلية الأولية، لكن الترخيص هنا
**حالةٌ في قاعدة البيانات يفرضها الخادم** على المركزي والفروع مع كل طلب —
لا رموز تُلصق ولا شيء في يد العميل يمكن تزويره.

| النموذج الأولي | هنا |
|---|---|
| ترخيص شركة | متجر حقيقي + حساب مالكه (شاشة «متجر جديد») |
| مدة الاشتراك / 0 = بلا انتهاء | نفسه — مع تجديدٍ يضاف لما تبقّى |
| مفتاح فرع + نموذج التشغيل | الفرع ينشئه المالك من المركزي داخل السقف، ونموذجه يُضبط من هنا |
| تحقّق | صفحة المتجر: حالته الفعلية كما يراها الخادم |
| السجل في المتصفح | `platform_log` في القاعدة + تصدير CSV |

## التشغيل

```bash
npm install
cp .env.example .env   # واضبط VITE_API_URL
npm run dev
```

## أول دخول

1. في الباك إند: شغّل `db/migrations/032_platform_admin.sql`، وتأكد أن
   `PLATFORM_ADMIN_KEY` مضبوط في متغيرات البيئة.
2. افتح اللوحة — تظهر شاشة «إنشاء أول حساب». أدخل المفتاح واسمك وبريدك
   وكلمة مرور.
3. بعد أول حساب يُقفل هذا المسار نهائيًّا، والدخول بالبريد وكلمة المرور.

## النشر

مثل ounce-central تمامًا (`npm run build` ثم `npm start`). اضبط
`VITE_API_URL` و`VITE_CENTRAL_APP_URL` **قبل البناء** (متغيرات وقت البناء)،
وأضف دومين اللوحة إلى `CORS_ORIGIN` في الباك إند.
